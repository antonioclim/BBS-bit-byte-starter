03 / Distance and guarantees

Why can we detect two errors but correct one?

One error = one flipped bit. Example: send 0 as 000 and 1 as 111.

The only valid codewords: 000 and 111
They differ in all 3 positions: dmin = 3.

In this simulation, we send 000. The receiver gets:

1. Detect: “Has anything changed?”

With 1 or 2 bit flips, 000 cannot become 111. The result is not a valid codeword, so we detect an error.

2. Correct: “What was the original?”

With at most 1 bit flip, the original is still the nearest codeword. With 2 flips, 011 is closer to 111: we may choose the wrong codeword.

e = how many errors we want to detect with a guarantee.
dmin ≥ e + 1 → here e ≤ 2
c = how many errors we want to correct with a guarantee.
dmin ≥ 2c + 1 → here c ≤ 1

dmin = the smallest distance between two valid codewords.

Detect up to 2 OR correct up to 1; we cannot always distinguish 1 error from 2.

03 / The limits of correction

What if the assumption is violated?

A decoder designed for one error can misinterpret two errors.

Original codeword: 0011001
Introduce two errors: positions 3 and 5.
The syndrome is 6. The decoder assumes an error at position 6.
It flips another bit. It obtains a valid codeword, but the data becomes 0111.

A zero syndrome means the checks pass. Guaranteed recovery depends on the assumption holding.

An extension called SECDED can distinguish double errors from single errors.

05 / Programming decisions

Which mechanism should we choose?

The choice depends on the problem and on how data can be recovered.

We can request the data again

The transfer can be repeated.

Detection + retransmission, within the checking mechanism’s limits.

We must recover the data locally

Retransmission is unavailable or too costly.

An error-correcting code suited to the error model and available redundancy.

An attacker is a concern

Data may be changed deliberately.

Cryptographic authentication: for example, a MAC or signature in an appropriate protocol.

An attacker can alter the message and recalculate the CRC. A CRC alone does not authenticate the sender.
In practice, mechanisms can be combined at different layers.

Hamming (7,4) + overall parity. The model here assumes at most two errors.

SEC: single error correction.
DED: double error detection.

CRC and burst errors

A burst’s length is measured from the first flipped bit to the last, inclusive.

For a degree-r generator with constant term 1, every burst of length ≤ r is detected.
