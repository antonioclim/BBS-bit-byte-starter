What we will learn

  • Calculate NOT, AND, OR and XOR and explain the case distinguishing OR from XOR.
  • Translate an access rule into a parenthesised expression without removing its mandatory condition.
  • Construct and read a complete table with an explicit row convention.
  • Transcribe a two-block circuit into an expression and check its output.
  • Check simple equivalences on every row and reject a claim with a counterexample.
  • Construct a simple canonical SOP from rows whose output is 1.
  • Trace a short execution and distinguish registers, main memory, storage and devices.

Why this will help

  • Write conditions precisely enough for another person to implement and test them.
  • Separate the intention, the entered expression and the calculated output.
  • Check explanations from Gemini with an independent calculation including unfavourable cases.

What to retain after the steps fade

  • Define inputs and conventions before calculating.
  • Inclusive OR and XOR differ when two inputs are both true.
  • Equivalence requires matching results on every row of the domain; one differing row rejects it.
  • Canonical forms are constructed from a table and are not automatically minimal.
  • A combinational circuit calculates from current inputs; registers and memory retain state.
  • In a trace declare address units and track PC, ACC and changed memory separately.

The core route connects logic gates, truth tables and expression checking to program execution in a teaching computer. We use two or three variables; four variables and extended canonical forms are for reference. The processor model is declared explicitly and does not claim to reproduce a commercial processor.

01 · In the seminar · orientation · approximately 8 min

S04 · From a rule to a verifiable result

A Boolean function assigns a result of 0 or 1 to every combination of inputs of 0 or 1. A rule, an expression, a table and a circuit can describe the same function.

Why this method works

When a program decides whether to grant access, whether a condition is satisfied or whether to flag a problem, its rule must be precise. A plausible description is insufficient: we need to calculate and check every case.

Steps to follow

  1. Follow the core in the suggested order; supplements support reference and preparation for more advanced questions.
  2. Record your predicted result before using the tool.
  3. Complete the main examples within their time slots. These pages support work and later reading; they are not a script to read aloud in full.

Before the first calculation

You need to distinguish 0 from 1 and read a three-bit string in the declared order. Check: at ABC = 101, what is B? If you do not get 0, return to the conventions and write A, B and C separately. No electronics or programming experience is required.

The likely difficulty is moving from words to parentheses: authentication must remain mandatory. Later, in the processor model, distinguish an address from the value at that address. Keep intermediate calculations so you can see where to resume.

What we will build

We begin with four operations: NOT, AND, OR and XOR. We then construct the access rule F = A AND (B OR C), complete its table and read a circuit with two blocks. We check two identities and rebuild the expression from rows whose output is 1.

We allocate approximately ten minutes of work to tracing four instructions in a teaching computer. The connection is straightforward: circuits calculate functions and memory retains the state needed to execute a program. No installation or assembly language is required.

A mistake to avoid: Memorising symbols without defining the inputs leaves the rule incomplete.

In S05–S07 we will write requirements and tests for a project. A complete table shows which cases deserve checking.

02 · In the seminar · orientation · approximately 8 min

Declare the convention before calculating

Here 1 means true and 0 means false. A, B, C and D are logical variables; both their order and the row order are declared.

Why this method works

The same bit may represent a digit, a condition or part of a character. The convention supplies its meaning. A table is easier to check when everyone uses the same order.

Steps to follow

  1. For n variables, list all 2ⁿ combinations.
  2. Order rows as ascending binary numbers, with A on the left as the most significant bit.
  3. Number rows from 0. The truth vector contains one output per row in this order.
Two conventions to keep distinct

For A and B, the rows are 00, 01, 10, 11. For A, B and C, they are 000, 001, 010, 011, 100, 101, 110, 111. The index is 4A + 2B + C. An eight-bit vector describes eight outputs, not a single input value.

Use parentheses in expressions. Without them, the tool applies NOT > AND > XOR > OR. Boolean + and · mean OR and AND: therefore 1 + 1 = 1 in Boolean algebra. The integer sum is 2. In a physical circuit, declared signal ranges represent 0 and 1; these symbols do not imply one universal voltage.

Try before opening the answer

What is the index of row ABC = 101, when numbering starts at 0?

Answer and verification

5

4×1 + 2×0 + 1 = 5. It is not the fifth row when row positions are counted from 1.

A mistake to avoid: A truth vector without the variable and row order is an incomplete specification.

A reproducible test keeps its convention alongside the data and expected result.

03 · In the seminar · gates · approximately 18 min

NOT · Negate a condition

NOT changes 0 to 1 and 1 to 0. It takes one logical input; parentheses determine which expression is negated.

Why this method works

“Not authenticated” differs from “authenticated”. Negation is simple, but its position in an expression can change the whole rule.

Steps to follow

  1. Evaluate the expression inside parentheses first.
  2. Apply NOT once to its result.
  3. For two consecutive negations, check both inputs: NOT(NOT A) = A.
What changes and what stays the same

For NOT A, input A = 0 gives 1 and A = 1 gives 0. Its vector is 10. For NOT(NOT A), the vector is 01, identical to A.

In an access rule, NOT(A AND B) negates the combined result. (NOT A) AND B negates only A. At A = 0, B = 0, the first expression returns 1 and the second returns 0. Moving parentheses therefore changes more than the appearance.

The tool accepts NOT, ! or ¬. We begin with the word form because it is easier to read. Textbook apostrophe notation must be translated: A′ becomes NOT A.

Try before opening the answer

What is NOT(NOT 1)?

Answer and verification

1

The first negation gives 0; the second gives 1.

A mistake to avoid: Negating a whole expression differs from negating one of its variables.

When a test fails, check the scope of negation as well as the variable value.

04 · In the seminar · gates · approximately 18 min

AND · Both conditions are required

A AND B is 1 only when A = 1 and B = 1. With two inputs, its vector is 0001.

Why this method works

A requirement such as “authenticated and authorised” is not satisfied when either condition is missing. AND expresses this requirement precisely.

Steps to follow

  1. List the four pairs 00, 01, 10 and 11.
  2. Mark 1 only for pair 11.
  3. Read the output column in row order: 0001.
Checking a two-part requirement

A means “the student is authenticated” and B means “the student has access rights”. At A = 1, B = 0, the student is authenticated but A AND B denies access. The result is 0. At A = 1, B = 1, the result is 1.

AND has an identity element: A AND 1 = A. In contrast, A AND 0 = 0. Check both relations at A = 0 and A = 1. They explain why a permanently false condition blocks a conjunction whereas a permanently true condition leaves it unchanged.

The tool treats &, * and · as AND aliases. A similarly shaped operator in a programming language does not automatically have the same types or evaluation rules.

Try before opening the answer

What is 1 AND 0?

Answer and verification

0

Both inputs must be 1; the second is 0.

A mistake to avoid: AND does not mean “at least one condition”.

AND will express mandatory authentication in our main rule.

05 · In the seminar · gates · approximately 18 min

OR · At least one condition is sufficient

A OR B is 1 when at least one input is 1. This is inclusive OR: pair 11 also returns 1.

Why this method works

In everyday language, “or” may suggest an exclusive choice. A software requirement must specify whether two simultaneously true conditions are allowed.

Steps to follow

  1. Check the case where both conditions are false.
  2. Then check each case with one true condition.
  3. Do not omit pair 11: OR returns 1 for it.
An alternative that allows both conditions

B means “the fee is paid” and C means “an approved exemption exists”. B OR C holds when the fee is paid, when the exemption exists or when both hold. There is no reason to deny access to someone who has both payment and exemption.

For two variables in order 00, 01, 10, 11, the vector is 0111. Check A OR 0 = A and A OR 1 = 1 at both values of A.

The tool accepts OR, | or +. Writing A + B still gives a Boolean result. It is not integer addition and does not produce 2.

Try before opening the answer

Write the vector of A OR B for rows 00, 01, 10, 11, without spaces.

Answer and verification

0111

Only pair 00 returns 0.

A mistake to avoid: In this lesson OR allows both inputs to be 1.

Ambiguities in everyday language become explicit tests when writing a requirement.

06 · In the seminar · gates · approximately 18 min

XOR · With two inputs, exactly one is true

A XOR B is 1 when A and B differ. Pairs 00 and 11 return 0; the vector is 0110.

Why this method works

XOR is useful for identifying a difference. In S03 we used it for parity calculations and polynomial division.

Steps to follow

  1. Compare the inputs rather than adding integers.
  2. Check pair 11: XOR gives 0 and OR gives 1.
  3. With several chained inputs, XOR returns 1 for an odd number of ones, not only for exactly one.
A comparison that prevents a common mistake
Three operations on the same four pairs.
ABANDORXOR
00000
01011
10011
11110

1 XOR 1 = 0. Equal values cancel under XOR. Hence A XOR A = 0 and A XOR 0 = A. The tool treats ^ as a XOR alias.

With three inputs, 1 XOR 1 XOR 1 = 1: the first pair gives 0 and 0 XOR 1 gives 1. “Exactly one” must be restricted to two inputs. For more inputs, the rule is odd parity of the number of ones.

Try before opening the answer

What is 1 XOR 1?

Answer and verification

0

The inputs are equal. XOR is 1 only when the two inputs differ.

A mistake to avoid: OR and XOR agree on three rows but differ at 11.

One counterexample will be enough to reject replacing OR with XOR.

07 · In the seminar · gates · approximately 18 min

Use the tool after making a prediction

The tool calculates the expression you enter. It cannot decide whether that expression matches the requirement you intended.

Why this method works

A transcription mistake may produce a perfectly calculated table for the wrong function. Check the tool input as well as its output.

Steps to follow

  1. Select two variables and enter A OR B explicitly. Before calculating, record the predicted vector 0111.
  2. Generate the table and compare all four rows with your prediction.
  3. Repeat for A XOR B, then compare the expressions to locate their differing row.
A correct result for the wrong question

If you enter A AND B instead of A OR B, the tool returns 0001. This is correct for the entered expression but does not answer the OR requirement. Read the expression again before changing your paper calculation.

Select the required number of variables. Two variables give four rows; three give eight. An expression that does not use C can be evaluated on a three-variable domain, but every result repeats for C = 0 and C = 1. Therefore vectors cannot be compared directly when their widths or domains differ.

If the tool rejects an expression, check parentheses, variable names and supported operations. Do not enter commas or notation such as Σm into the expression field.

If the result does not match

For an OR requirement, vector 0001 suggests that you entered AND. First check row AB = 01: OR must give 1 whereas AND gives 0. If the field contains AND, change only that operator and recalculate all four rows. If it already contains OR, check the row order before changing the expression.

If the result has eight positions instead of four, selecting three variables is one possible cause. Check the selector and row pairs differing only in C. Return to the required AB domain and rebuild the table; continue when it has four rows in order 00,01,10,11.

A mistake to avoid: An automatic calculation checks the supplied expression, not an unwritten intention.

The same principle applies to project tests: check the data the program actually received.

08 · In the seminar · rule and circuit · approximately 22 min

Translate the access rule without changing its meaning

Access requires authentication and, additionally, either payment or exemption: F = A AND (B OR C).

Why this method works

A correct expression must preserve the mandatory condition. Under this rule an exemption does not authorise an unauthenticated person.

Steps to follow

  1. Define A = authenticated, B = fee paid and C = approved exemption.
  2. Group alternatives B and C inside parentheses.
  3. Connect the whole group to mandatory condition A with AND.
Two descriptions that appear similar

The agreed rule is A AND (B OR C). At ABC = 001, an exemption exists but authentication is missing: the output is 0. At ABC = 101, authentication and exemption are both present: the output is 1.

(A AND B) OR C would grant access at 001 because C alone would suffice. It describes a different rule. It is not an equivalent rewriting. One carefully chosen case reveals the difference.

The conditions are already established logical values. We are not building real authentication, verifying a payment or collecting personal data. We are learning to formalise a decision and observe the behaviour implied by its wording.

Build your own case within the discussion

Instead of repeating another solved calculation, propose a different situation with one mandatory condition A and two alternatives B and C. Define them without personal data and write the rule in words, then as an expression. Choose an allowed input and a refused input yourself; record X = B OR C and F before checking. Explain why each result respects your rule.

Predict whether (A AND B) OR C would preserve that rule. Look for a row that would falsify the claim rather than one on which the expressions agree. Keep the input and both outputs.

Hint 1 · Which condition must remain mandatory?

Under your rule, A = 0 must block access regardless of the alternatives. Look for an input where the proposed form bypasses that condition.

Hint 2 · Separate the intermediate calculations

With A = 0, calculate B OR C and A AND B separately. Then choose C so that the final OR in the proposed form can give 1.

An example, after your attempt

One possible situation: A = registered for a workshop, B = place confirmed and C = approved guest. At ABC = 011, the correct rule gives X = 1 and F = 0; the proposed form gives A AND B = 0, then 0 OR 1 = 1. This row disproves equivalence. If you obtained F = 1, check the final AND and the parentheses; correct only the mistaken step, then redo all eight rows.

Try before opening the answer

What does the correct rule return at ABC = 001?

Answer and verification

0

A = 0 blocks the AND expression even though C = 1.

A mistake to avoid: Moving parentheses can remove a mandatory condition.

A precise requirement and a useful counterexample save debugging time.

The complete table · Leave no case to guessing

A complete three-variable table has eight rows. Intermediate columns show how every result is obtained.

Why this method works

Checking only examples with A = 1 could miss an expression that grants access without authentication. Exhaustive checking of this small domain forces us to include inconvenient cases.

Steps to follow

  1. List combinations from 000 to 111 and number them from 0.
  2. Calculate B OR C, then AND the intermediate result with A.
  3. Read F from top to bottom and retain all eight positions.

10 · In the seminar · rule and circuit · approximately 22 min

Evaluate from the inside out

Parentheses take priority. Evaluate their subexpressions before the operation that uses them.

Why this method works

A result that happens to be right does not establish a correct method. Recording intermediate values identifies exactly where an interpretation changed.

Steps to follow

  1. At ABC = 110, record A = 1, B = 1 and C = 0 separately.
  2. Calculate B OR C = 1.
  3. Apply AND between A and this value: 1 AND 1 = 1.
One input, two expressions

At ABC = 001, A AND (B OR C) returns 0. However, A AND B OR C is interpreted under the declared precedence as (A AND B) OR C and returns 1. Parentheses remain useful even when precedence rules are known.

At ABC = 111, both expressions return 1. That row does not distinguish them and does not prove equivalence. Choose a case in which the moved part, C, can act while A is 0.

To reproduce the calculation in the tool, enter A AND (B OR C). The parser accepts variables A to D, constants 0 and 1 and the declared operations. Do not enter the descriptive condition names as variables or use implicit multiplication such as AB.

Try before opening the answer

What does (A AND B) OR C return at ABC = 001?

Answer and verification

1

A AND B is 0 but C is 1, so OR gives 1.

A mistake to avoid: One example on which two expressions agree does not prove their equivalence.

Keep the parenthesised form in documentation, tests and explanations requested from an LLM.

11 · In the seminar · rule and circuit · approximately 22 min

Read a circuit by following its connections

Each block applies an operation to its inputs. In our circuit OR receives B and C; AND receives A and the OR output.

Why this method works

A drawing is useful only when we follow its connections. The block name and the inputs actually connected to it matter more than its position on the page.

Steps to follow

  1. Start at the inputs and follow the lines towards the output.
  2. Name the intermediate output X = B OR C.
  3. Write F = A AND X, then substitute X: F = A AND (B OR C).
Two blocks, the same rule

At ABC = 101, OR receives 0 and 1, so X = 1. AND receives A = 1 and X = 1, so F = 1. At ABC = 001, X remains 1 but AND receives A = 0 and returns F = 0.

The drawing uses labelled rectangular blocks without claiming a particular electronic symbol library. The function is also stated in text so it can be followed without the drawing. Delays, voltages and internal state are not modelled: this is an idealised combinational circuit.

The next example changes the rule: A selects between B and C instead of requiring authentication. We use it to check whether we can follow two branches, not as a rewriting of the access rule.

Short transfer: two branches

Now consider F = ((NOT A) AND B) OR (A AND C). The first branch calculates X = (NOT A) AND B; the second calculates Y = A AND C; the final block returns X OR Y. With A = 0 the function becomes B. With A = 1 it becomes C. At ABC = 011, X = 1, Y = 0 and F = 1.

The complete vector is 00110101 in ABC order 000…111. Follow each branch separately before the final output. This is a transfer example for reference, not an extra activity added to the time slot.

Try before opening the answer

At ABC = 100, what is the intermediate output X = B OR C?

Answer and verification

0

Both B and C are 0. AND receives 1 and 0, so F = 0.

A mistake to avoid: A visual crossing alone does not establish a connection; connections must be indicated clearly.

An expression and a drawing can check each other when they share the same inputs and outputs.

12 · In the seminar · equivalence · approximately 14 min

Equivalence · Match every row

Two expressions are equivalent on the declared domain when they return the same result for every input combination. One differing row is a sufficient counterexample.

Why this method works

When modifying a program we often want a simpler form without changing behaviour. We need a checkable criterion rather than visual similarity.

Steps to follow

  1. Use the same variable and row order for both expressions.
  2. Compare all 2ⁿ results, not only favourable cases.
  3. If a difference exists, record its index, inputs and both outputs.
OR and XOR are not interchangeable

For A and B, OR has vector 0111 and XOR has vector 0110. They differ at index 3, AB = 11: OR = 1 and XOR = 0. Indices 0, 1 and 2 do not reveal the difference.

In the access rule, replacing B OR C with B XOR C would deny access at ABC = 111. That changes behaviour even if the remaining cases agree.

For a small Boolean domain, comparing every row is exhaustive. For a program with many more possible inputs, a finite test set we select does not automatically cover every behaviour. This lesson provides a case where a complete check is feasible.

Check a rewriting you propose yourself

Within the same discussion, return to your rule. Propose another expression with the same three variables, using negation, factorisation or a changed operator. First state whether you expect it to be equivalent and why. Look for a row that would falsify the claim “the expressions are equivalent”, even if you predict a difference. Then compare all eight rows. If they differ, keep the first differing row and both outputs; if they do not, your conclusion rests on the complete table rather than the chosen row.

Hint 1 · Choose a row that challenges the change

For a changed operator, look for inputs on which the operations differ. For a moved negation, calculate the expression being negated and the result of negating it separately.

Hint 2 · Locate the first mismatch

Write the output of every block or subexpression on your chosen row. If the output differs from the rule in words, check the exact operator, parenthesis or connection causing the first difference. If the intention was to preserve the rule, correct that element and repeat the comparison on all eight rows.

Continue when you can explain whether the rewriting preserves the rule, using the complete table or a counterexample. For the circuit, check that every transcribed connection matches the expression. A counterexample rejects an equivalence; it does not mean that the tool is faulty.

Try before opening the answer

What is the zero-based index of the counterexample to A OR B versus A XOR B?

Answer and verification

3

At AB = 11, OR gives 1 and XOR gives 0. Its index is 2A + B = 3.

A mistake to avoid: Agreement on a few rows does not prove agreement on all rows.

In Git we can change the form of code and use tests to track changes in behaviour.

De Morgan · Negation also changes the operation

NOT(A OR B) = (NOT A) AND (NOT B). Similarly, NOT(A AND B) = (NOT A) OR (NOT B).

Why this method works

Negating a compound condition cannot be done by negating its terms while keeping the operation unchanged. That mistake can reverse a decision.

Steps to follow

  1. Calculate the original expression on all four rows.
  2. Calculate the proposed equivalent expression separately.
  3. Compare the complete columns, then state the identity.
Check the first identity completely
Both expressions have vector 1000.
ABNOT(A OR B)(NOT A) AND (NOT B)

0100
1000

At AB = 01, NOT A = 1 and NOT B = 0. AND gives 0, matching the negation of OR. The incorrect alternative (NOT A) OR (NOT B) would give 1.

For the second identity, the common vector is 1110. Moving negation across an operation changes OR to AND or AND to OR and negates each operand. Retain parentheses until the rule is clear.

Try before opening the answer

Write the vector of NOT(A OR B) in order 00, 01, 10, 11, without spaces.

Answer and verification

1000

Only at 00 does OR equal 0, so its negation returns 1.

A mistake to avoid: NOT(A OR B) is not equivalent to (NOT A) OR (NOT B).

Check the negation of a rule as carefully as the original rule.

14 · In the seminar · equivalence · approximately 14 min

Factorisation · One condition, another form

(A AND B) OR (A AND C) = A AND (B OR C). In Boolean notation: AB + AC = A(B + C).

Why this method works

An expression may repeat a condition. Factorisation exposes the shared part and can make the rule easier to read.

Steps to follow

  1. Identify A in both terms joined by OR.
  2. Write A AND the group B OR C.
  3. Check all eight rows and confirm that the vector remains 00000111.
Two forms of the access rule

(A AND B) OR (A AND C) grants access through authentication and payment or through authentication and exemption. A AND (B OR C) requires authentication together with either alternative. Both produce 00000111.

At ABC = 110, A AND B is 1 and A AND C is 0, so OR gives 1. The factored form calculates B OR C = 1, then A AND 1 = 1. At ABC = 001, both forms give 0.

In this representation the factored form uses two binary operations and the expanded form uses three. That does not prove every physical circuit or program will run faster. Cost also depends on the implementation, library and delays.

Two simple checks across all four rows

A OR (A AND B) = A: when A = 0 both terms are 0; when A = 1 the first term is already 1. The shared vector on the AB domain is 0011. This identity is called absorption.

((NOT A) AND B) OR (A AND B) = B: factor B to obtain ((NOT A) OR A) AND B = 1 AND B. The common vector is 0101. Both relations can be checked on the four rows without memorising a new procedure.

Try before opening the answer

At ABC = 101, what does (A AND B) OR (A AND C) return?

Answer and verification

1

The first term is 0 and the second is 1. OR gives 1.

A mistake to avoid: Textbook AB denotes AND without a symbol. In the tool write A AND B explicitly.

A useful simplification preserves behaviour and explains the requirement more clearly.

15 · In the seminar · equivalence · approximately 14 min

From rows with 1 to a sum of products

For each row with F = 1, construct an AND term that is true only on that row. Join these terms with OR.

Why this method works

This is a general way to construct an expression from a complete table. We need not guess the formula or claim the resulting form is minimal.

Steps to follow

  1. For F = A AND (B OR C), select indices 5, 6 and 7.
  2. In each term use the variable for bit 1 and its negation for bit 0.
  3. Join the selected row terms with OR.
Three rows, three minterms

Row 5, ABC = 101, gives A AND (NOT B) AND C. Row 6, ABC = 110, gives A AND B AND (NOT C). Row 7, ABC = 111, gives A AND B AND C.

The canonical SOP is (A AND NOT B AND C) OR (A AND B AND NOT C) OR (A AND B AND C), written Σm(5,6,7) under the declared convention. Its vector is 00000111, matching the shorter form.

“Canonical” means that each term includes all three variables, each complemented or uncomplemented. “Sum” and “product” are the traditional names for OR and AND in this algebra. The form is constructed mechanically; simplification is a separate step.

Transfer: odd rows and one variable

On the ABC domain Σm(1,3,5,7) selects 001,011,101,111. C = 1 on each row while A and B cover every combination. The function is C with vector 01010101. Check the four even-indexed rows too: each has C = 0.

A SOP such as (A AND B) OR (A AND C) OR (B AND C) may be a correct expression without being canonical in three variables: every term omits one variable. Similarly, (A OR B) AND (A OR C) AND (B OR C) is noncanonical POS. “SOP/POS” and “canonical SOP/POS” are not synonymous.

Try before opening the answer

How many rows give output 1 for the main rule?

Answer and verification

3

They are rows 5, 6 and 7. Its canonical SOP has one minterm for each.

A mistake to avoid: In a minterm bit 0 requires a negated variable. Maxterms follow a different rule.

We can rebuild an implementation from specified behaviour and then check equivalence.

A computer contains more than a processor

Our simplified model separates the CPU, main memory, input/output devices and persistent storage. Each has a role.

Why this method works

A logical output alone does not explain how a program runs. We must know where instructions and data are held and which component processes them.

We change examples here because a truth table describes a function of current inputs whereas executing a program also requires state. We retain the method: an explicit convention, a prediction, intermediate steps and a check. The numeric pair 7 and 5 lets us observe registers and memory without adding branches or new instructions.

Steps to follow

  1. Identify the CPU as the component that interprets and executes instructions in this model.
  2. Distinguish main memory from storage that retains files.
  3. Follow one transfer: an instruction from memory to CPU, then data from memory to a register.
Four roles, without product specifications

The CPU is not the entire computer. In a stored-program model, instructions and data are available in memory. The term “von Neumann model” names a classical organisation; it does not claim that every modern computer has exactly this structure or that one person invented all these ideas.

A combinational circuit calculates from current inputs. Registers and memory introduce state: a present value may depend on earlier operations.

A mistake to avoid: Confusing a processor with the entire computer obscures the roles of memory, storage and devices.

A program changes machine state; a trace makes these changes visible.

18 · In the seminar · architecture · approximately 10 min

Memory, registers and storage · Ask what they do

Registers hold values used directly by the CPU. Main memory holds working instructions and data; persistent storage retains files between sessions.

Why this method works

“Where is the value?” matters when explaining execution. A saved file and a register value have different roles even though both are represented by bits.

Steps to follow

  1. Our teaching machine uses ACC for a numeric value and PC for the instruction address.
  2. Reading memory does not automatically erase the cell that was read.
  3. Distinguish changing a register from writing a result into memory.
A value can be present in two places

If memory address 12 contains 7, LOAD 12 makes ACC equal 7. Cell 12 remains 7. Later, ADD 13 can change ACC without altering cell 12 or cell 13. Only STORE 14 writes the result to address 14.

Typical DRAM main memory loses data without power and requires refresh during operation. An SSD retains data without power. However, RAM describes an access property and does not establish that every technology called RAM is volatile.

We are not memorising product capacities or speeds. The useful question to retain is whether the component calculates, holds a working value or retains a file.

Try before opening the answer

After LOAD 12, if memory[12] held 7, what does memory[12] hold?

Answer and verification

7

LOAD copies the value into ACC without erasing the source cell.

A mistake to avoid: Loading a value is not a move that erases the source.

When debugging, track working values separately from stored results.

19 · In the seminar · architecture · approximately 10 min

One instruction · Fetch, interpret, apply its effect

PC identifies the current instruction address. The model fetches the instruction, interprets it and applies its effect to registers or memory.

Why this method works

A final result alone does not show why it occurred. A trace containing PC, instruction, ACC and changed memory explains execution step by step.

Steps to follow

  1. Start with PC = 0 and ACC = 0.
  2. Fetch the instruction from the cell selected by PC and read its operand.
  3. Execute the operation, then increment PC by 1 for LOAD, ADD and STORE. At HALT stop and retain PC at the HALT address.
Our machine convention

There are 16 cells addressed 0…15. An instruction cell contains a description such as LOAD 12; a data cell contains an unsigned 8-bit integer. This is typed teaching notation rather than the actual binary encoding of an instruction.

ACC ranges from 0 to 255. ADD a calculates (ACC + memory[a]) mod 256. The model permits inspection of wrap-around, although the main example does not exceed 255.

PC advances by one instruction cell, not one byte or four bytes. Fetch–decode–execute is a conceptual sequence. It does not assert that every instruction on a modern processor occupies exactly one clock cycle.

Try before opening the answer

After executing LOAD from cell 0, what is PC in this model?

Answer and verification

1

This instruction is not HALT, so PC advances one cell from 0 to 1.

A mistake to avoid: An instruction address, a data value and a byte count are different quantities.

Keep the execution convention next to the trace, just as row order belongs next to a table.

Canonical POS · Start with rows containing 0

For each row with F = 0, construct an OR clause that is false only on that row. Join the clauses with AND.

Why this method works

POS is dual to SOP, but its rule for complemented variables is reversed. Applying the minterm rule mechanically produces the wrong function.

Steps to follow

  1. For the main rule, select zero rows 0, 1, 2, 3 and 4.
  2. In a maxterm use the uncomplemented variable for bit 0 and its complement for bit 1.
  3. Join the maxterms with AND and check all eight rows.
POS for the same access rule

For row 000 the maxterm is A OR B OR C: it is 0 only when all variables are 0. For row 100 the maxterm is (NOT A) OR B OR C: all three literals are 0 on that row.

The complete form is (A OR B OR C) AND (A OR B OR NOT C) AND (A OR NOT B OR C) AND (A OR NOT B OR NOT C) AND (NOT A OR B OR C), written ΠM(0,1,2,3,4). Its vector is 00000111, matching the SOP.

A product of sums may be noncanonical. For example, A AND (B OR C) is a simple POS but not a canonical three-variable POS: its clauses do not each contain all variables. “Canonical” does not mean “minimal”.

Try before opening the answer

How many maxterms are in the main rule’s canonical POS?

Answer and verification

5

There are five rows with F = 0: 0, 1, 2, 3 and 4.

A mistake to avoid: In SOP bit 0 requires negation; in POS bit 1 requires negation.

If assessment includes canonical POS, preparation must explicitly include this method.

Karnaugh · Adjacent cells differ in one bit

In a four-variable map, AB rows and CD columns use Gray order 00, 01, 11, 10. Adjacent cells differ in one variable; opposite edges join.

Why this method works

The ordinary order 00, 01, 10, 11 does not preserve the adjacency required for grouping. A map without clear labels cannot be interpreted reliably.

Steps to follow

  1. Place the previous example’s outputs with AB on rows and CD on columns.
  2. For SOP, group only 1 cells in rectangles of 1, 2, 4, 8 or 16 cells; groups may wrap across edges and overlap.
  3. Retain only the variables constant within each group. Verify the resulting expression against the table rather than the drawing alone.

Don’t-care · Declared freedom, not a required output

A don’t-care row has no output prescribed by the specification. We may implement it as 0 or 1 while preserving every prescribed row.

Why this method works

An answer key may be wrong if it treats don’t-care as a mandatory 1 or if simplification alters a non-free row. Two implementations can both be valid and differ on free rows.

Steps to follow

  1. Separate prescribed ones, prescribed zeros and free rows without overlap.
  2. For SOP grouping, use a don’t-care as 1 only when useful; it need not be covered. For POS, it can similarly be used as 0.
  3. Check the final expression on every prescribed row, then record the choices made for free rows.
A SOP example with free conditions

In ABCD order prescribe 1 at {1,3,5,9} and don’t-care at {6,7,11}; all remaining rows are 0. A valid simplification is D AND ((NOT A) OR (NOT B)). It returns 1 at 1,3,5,7,9,11 and 0 elsewhere. Thus we choose 6 → 0, 7 → 1 and 11 → 1 without violating any prescribed row.

A POS example: removing a required term

Prescribe 0 at {0,1,3,9} and don’t-care at {7,11}; all remaining rows are 1. A valid form is (A OR B OR C) AND (B OR NOT D). Its zeros are 0,1,3,9,11; here we chose 7 → 1 and 11 → 0.

(A OR B) AND (B OR NOT D) is incorrect: at row 2, ABCD = 0010, it returns 0 although that row must be 1. Removing C is not allowed. The ordinary tool calculates complete functions; it does not infer free rows unless they are declared separately.

Try before opening the answer

In the POS example, which result must be preserved at index 2?

Answer and verification

1

Index 2 is neither a prescribed zero nor a don’t-care. The example therefore prescribes 1.

A mistake to avoid: A don’t-care expresses design freedom, not a numeric bit of value 2 or a compulsory output.

The specification must declare permitted cases before that freedom is used for simplification.

NAND and NOR · The same function with other blocks

NAND(A,B) = NOT(A AND B) and NOR(A,B) = NOT(A OR B). Either gate type alone can construct any finite Boolean function.

Why this method works

Universality means we can build NOT, AND and OR using one gate type. It does not mean an isolated gate implements every function.

Steps to follow

  1. For NOT, connect the same input to both inputs of a NAND or NOR.
  2. Construct AND from a NAND followed by negation of its output.
  3. Construct OR from NAND gates and negated inputs using De Morgan, then check all four rows.
Constructions and an important limitation

NOT A = NAND(A,A). If X = NAND(A,B), then AND(A,B) = NAND(X,X). For OR, NAND(NAND(A,A), NAND(B,B)) produces NOT((NOT A) AND (NOT B)) = A OR B.

Similarly, NOT A = NOR(A,A) and negating a NOR output produces OR. Constructing AND with NOR uses negated inputs and De Morgan.

Do not regroup NAND or NOR freely: their binary operations are not associative. At A,B,C = 0,0,1, NAND(NAND(A,B),C) gives 0 whereas NAND(A,NAND(B,C)) gives 1. The corresponding NOR forms give 0 and 1 at 0,0,1. In the expression tool translate NAND into NOT(... AND ...) and NOR into NOT(... OR ...); NAND and NOR are not parser operators.

Try before opening the answer

What is NAND(1,1)?

Answer and verification

0

AND(1,1) is 1, so its negation is 0.

A mistake to avoid: Universality does not imply associativity or justify omitting parentheses.

The same behaviour can have several implementations; compare the functions they calculate.

28 · Supplement for reference · Supplement · further reading

Limits of the architecture model

The ACC-and-PC machine explains a small execution. A modern processor may have more registers, caches, overlapping execution and a different memory-access organisation.

Why this method works

A teaching model is useful when we know what it retains and omits. Otherwise a calculation-friendly simplification may be mistaken for a claim about every device.

Steps to follow

  1. Distinguish a component’s role from its implementation details.
  2. In a classical unified organisation, instructions and data share memory; Harvard organisation separates their paths and memories.
  3. Compare what a functional trace can establish with what requires performance measurement or security analysis.
One execution idea, several implementations

A system may have a unified address space and separate instruction and data caches. Therefore von Neumann and Harvard labels do not classify every modern processor without qualification. Our seminar explicitly uses a unified model with typed cells.

Registers, cache, main memory and storage serve different roles within a hierarchy. Do not turn a qualitative comparison into a universal ranking of technologies or treat historical timings as current specifications.

Combinational circuits depend on current inputs under the stable logical model. A sequential system also has state. A clock can control when that state updates, but “one instruction” does not automatically mean “one clock cycle”. Our machine does not model actual binary instruction encodings, memory protection, interrupts or pipelines.

A mistake to avoid: Four teaching steps cannot establish a real processor’s speed, security or internal organisation.

Retain this question: which property does the model describe and what evidence would establish an additional claim?
