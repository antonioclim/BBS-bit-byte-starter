Cum începi / How to begin

Pentru citire și încercare

Din GitHub alegi Code → Download ZIP, extragi întregul folder și deschizi START.html în browser. Păstrează împreună folderele LESSONS, GUIDES și PROJECT.

For reading and trying the application

On GitHub choose Code → Download ZIP, extract the whole folder and open START.html in a browser. Keep the LESSONS, GUIDES and PROJECT folders together.

Pentru activitățile cu Git

În S05 creezi o singură dată repository-ul tău din șablonul comun, prin Use this template → Create a new repository. Clonezi în VS Code adresa repository-ului tău și lucrezi în aceeași clonă în S05–S07, urmând lecția.

For Git activities

In S05 create your own repository once from the shared template through Use this template → Create a new repository. Clone your own repository URL in VS Code and work in the same clone throughout S05–S07, following the lesson.

Ai început deja? Continuă în repository-ul propriu. Descărcarea ZIP este utilă pentru citirea noilor lecții, dar nu înlocuiește proiectul și istoricul tău. Un pull din repository-ul tău nu preia automat schimbările ulterioare din șablon.

Already started? Continue in your personal repository. A ZIP download helps you read the new lessons but does not replace your project and history. A pull from your repository does not automatically import later template changes.

Fișierele HTML apar ca sursă pe GitHub. Pentru lecțiile interactive și aplicație, deschide fișierele din folderul local extras sau clonat.

GitHub displays HTML files as source. For the interactive lessons and application, open the files from the extracted or cloned local folder.

Evaluarea S01–S07 / S01–S07 assessment

Cele șapte quizuri din Moodle valorează împreună maximum 3 puncte reale: Q01–Q04 câte 0,50 puncte, iar Q05, Q06 și Q07 câte 0,20, 0,30 și 0,50 puncte. Verificările locale din lecții sunt pentru exersare; evaluarea se desfășoară în Moodle.

Vezi repartizarea, durata și regulile evaluării

The seven Moodle quizzes together contribute at most 3 real points: 0.50 points each for Q01–Q04, then 0.20, 0.30 and 0.50 points for Q05, Q06 and Q07. Local lesson checks are for practice; assessment takes place in Moodle.

View the allocation, duration and assessment rules

Fișa finală a proiectului este obligatorie, fără notă separată; depunerea, completitudinea sau aprobarea ei nu condiționează accesul la Q07.

The final project record is compulsory and has no separate grade; submission, completeness or approval of it is not a condition for access to Q07.

În proiectul inițial ai două funcții de completat și o problemă pregătită pentru investigație. Începe cu etapa baseline; testele unei etape viitoare pot arăta rezultate incomplete sau greșite. Selectează etapa curentă conform lecției.
