Fişa comună de referinţă

Regulile şi operaţiile pe care le poţi consulta în lucru şi la quiz.

Opt biţi de date

Intrare: întreg zecimal u între 0 şi 255 inclusiv. Spaţiile de la capete şi zerourile iniţiale sunt acceptate; golul, textul, numerele negative, fracţiile şi 256 sunt respinse.

Binar: exact opt poziţii, cu ponderile 128, 64, 32, 16, 8, 4, 2 şi 1. Hexazecimal: exact două caractere, cu A–F majuscule; fiecare caracter descrie patru biţi, deoarece 16 = 2⁴. 255 = 15 × 16 + 15 → FF.

Complement faţă de doi: s = u dacă u < 128; s = u − 256 dacă u ≥ 128. Interval cu semn: −128…127. Biţii rămân aceiaşi; se schimbă interpretarea. Prima pondere devine −128.

Bitul de paritate este separat

k = numărul biţilor 1 din date. Paritate pară: p = k % 2. Paritate impară: p = 1 − (k % 2). Operatorul % dă restul împărţirii. p este 0 sau 1. Adăugat la dreapta: 8 biţi de date + p = un cuvânt de 9 biţi.

O schimbare de bit sau un număr impar de schimbări modifică paritatea. Un număr par o poate păstra. Paritatea simplă nu localizează şi nu corectează eroarea.

origin este numele legăturii către repository-ul online. main este ramura principală. git status arată starea; git remote -v arată adresa; git branch --show-current arată ramura; git rev-parse HEAD arată identificatorul complet. Starea locală curată nu dovedeşte singură publicarea. Dacă editezi după stage, schimbarea nouă trebuie selectată din nou ca să intre în commit.

Ce verifici şi ce poţi concluziona

Investigaţie: ipoteză proprie → afirmaţie Gemini/exemplu pregătit → test cu rezultat aşteptat → rezultat obţinut → concluzie. Un contraexemplu infirmă o afirmaţie universală. Testele la prag şi retestarea cazurilor deja corecte previn concluziile pripite.

Reproducere: ultimul commit şi push → clonare separată → main şi acelaşi SHA complet → aplicaţie şi teste din copia nouă. SHA-ul final se copiază în Moodle după publicare.

Evaluare: individual, fără AI/colegi; această fişă este permisă. Q05: 10 min, maximum 0,20 puncte; Q06: 10 min, maximum 0,30; Q07: 15 min, maximum 0,50. Total ≤ 1 punct. Tema finală este obligatorie, fără punctaj separat.
