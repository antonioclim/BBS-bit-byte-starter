Fișa comună de referință

Reguli și operații de consultat în timpul lucrului și al testelor Moodle.

Opt biți de date

Intrare: întreg zecimal u între 0 și 255 inclusiv. Sunt acceptate spațiile de la începutul și de la sfârșitul intrării și zerourile inițiale. Sunt respinse intrarea goală, textul nenumeric, numerele negative, valorile fracționare și valoarea 256.

Binar: exact opt poziții, cu ponderile 128, 64, 32, 16, 8, 4, 2 și 1. Hexazecimal: exact două caractere, cu A–F majuscule; fiecare caracter descrie patru biți, deoarece 16 = 2⁴. 255 = 15 × 16 + 15 → FF.

Complement față de doi (two’s complement): s = u dacă u < 128; s = u − 256 dacă u ≥ 128. Interval cu semn: −128…127. Biții rămân aceiași; se schimbă interpretarea. Prima pondere devine −128.

Bitul de paritate este separat

k = numărul biților 1 din date. Paritate pară: p = k % 2. Paritate impară: p = 1 − (k % 2). Operatorul % dă restul împărțirii. p are valoarea 0 sau 1. Bitul p se adaugă la dreapta celor opt biți de date; cuvântul transmis are nouă biți.

Modificarea unui singur bit sau a unui număr impar de biți schimbă paritatea. Inversarea unui număr par de biți în poziții distincte păstrează paritatea. Verificarea de paritate semnalează nepotrivirea parității, fără a localiza sau corecta eroarea.

Operațiile Git și rezultatul lor

Operațiile Git și rezultatul lor
OperațieRezultat
SaveFișier salvat pe calculator.
DiffDiferențe între stările comparate. git diff: schimbări neselectate.

CommitVersiune înregistrată în istoricul local.

IssueProblemă descrisă prin pașii de reproducere și rezultatele așteptate și observate.

Merge + pullIntegrare online, apoi git pull --ff-only actualizează main local.

origin este numele legăturii către repository-ul online. main este ramura principală. git status arată starea; git remote -v arată adresa; git branch --show-current arată ramura; git rev-parse HEAD arată identificatorul complet. Starea locală curată nu dovedește singură publicarea. Dacă editați după stage, modificarea nouă trebuie selectată din nou ca să intre în commit.

Ce verificați și ce puteți concluziona

Investigație: ipoteză proprie → afirmație din Gemini sau din exemplul pregătit → test cu rezultat așteptat calculat independent → rezultat obținut → concluzie. Un contraexemplu infirmă o afirmație universală. Testele la prag și retestarea cazurilor deja corecte previn concluziile pripite.

Reproducere: ultimul commit și push → clonare separată → main și același SHA complet → aplicație și teste din copia nouă. SHA-ul final se copiază în Moodle după publicare.

Evaluare: individual, fără AI sau ajutorul colegilor; această fișă este permisă. Q05: 10 min, maximum 0,20 puncte; Q06: 10 min, maximum 0,30; Q07: 15 min, maximum 0,50. Total ≤ 1 punct la seminar. Tema finală este obligatorie, fără punctaj separat.
