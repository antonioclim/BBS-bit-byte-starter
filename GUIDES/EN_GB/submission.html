What this submission does

This is the short record for the project you began in S05. It is compulsory and has no separate grade. Q05, Q06 and Q07 together contribute at most one real point. You do not need a PDF, screenshots or a full AI transcript.

Most fields will already be in your README.md and evidence.md. Complete the online-text area in the final Moodle assignment. A URL names the repository; the full SHA names the specific published version.

Before you copy the final SHA

  1. Save the required files, make the final commit and push it on main.
  2. From the original repository terminal, run git rev-parse HEAD and keep the full output.
  3. Clone your own repository into a new folder. Check that it is on main, has a clean working tree and shows the same full SHA.
  4. Open the HTML files from that new folder, then run S07 for your assigned variant and reproduce the three reported tests.

Do not put the final SHA inside a project file and commit again: that creates a new commit with a different SHA. Put it in Moodle after the last commit. If you change and republish the project, repeat the fresh-clone check and use the new SHA. Follow the full procedure in S07.
